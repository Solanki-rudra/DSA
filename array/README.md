# 🔢 Array Problems

This folder contains problems based on **arrays** — one of the most important data structures in DSA.  
Each subfolder focuses on a specific **technique or pattern** (like Hash Map, Two Pointers, Sliding Window, etc.) used to solve array-related problems efficiently.

---

## 📂 Folder Structure

| Folder | Description |
|---------|-------------|
| [`hash-map`](./hash-map) | Problems that use **Hash Maps** to solve array-related questions efficiently. |

- Understand different approaches for array-based problems.
