# 🔗 Queue Problems

This folder contains **Queue** problems — one of the most important and
frequently asked data structures in **DSA and coding interviews**.

The queue is a **First In, First Out (FIFO)** data structure that supports
enqueue (push), dequeue (pop), peek, and isEmpty operations.

---

## 📂 Folder Structure

| Folder | Description |
|--------|-------------|
| [`Queue.js`](./Queue.js) | Basic Queue implementation using an array with push, pop, peek, and isEmpty methods |
| [`design`](./design) | Problems involving designing advanced queue data structures, such as implementing queues using stacks and circular queues |
| [`bfs`](./bfs/) | Problems involving Breadth-First Search (BFS) techniques using queues to find shortest paths and minimum moves in graphs |

---

## 🧠 Key Learnings

- Understanding FIFO principle and queue properties
- Implementing queues with different underlying data structures
- Space-time trade-offs in queue implementations
- Queue applications in real-world problems

## 📚 Common Queue Problems

Queue is fundamental for solving problems involving:
- Breadth-First Search (BFS)
- Level-order traversal of trees
- Job scheduling and task management
- Resource allocation
- Sliding window problems
- Designing custom data structures using queues
