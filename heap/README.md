# 🔗 Heap Problems

This folder contains **Heap** implementations — an important data structure in
**DSA and coding interviews**.

The heap is a specialized tree-based structure commonly used to implement
priority queues. This folder focuses on max-heap behaviour and related problems.

---

## 📂 Folder Structure

| Folder | Description |
|--------|-------------|
| [`MaxHeap`](./MaxHeap.js) | Basic Max Heap implementation using an array with `push`, `poll`, `peek`, and `isEmpty` methods |
| [`max-heap`](./max-heap) | Problems and examples that use max-heaps (priority-queue style solutions) |

---

## 🧠 Key Learnings

- Understanding heap (max-heap) properties and invariants
- Implementing heap operations (`push`/insert, `poll`/remove-max) with array-backed heaps
- Space-time trade-offs and use-cases for heaps vs other structures
- Practical heap applications (priority queues, top-K, scheduling)

---

## 📚 Common Heap Problems

Heaps are fundamental for solving problems involving:
- Priority queues and scheduling
- Heap sort
- Finding top-K elements
- Merging K sorted lists
- Dijkstra's algorithm (priority queue usage)
- Running median / median maintenance
