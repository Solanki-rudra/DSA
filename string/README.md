# 🔢 String Problems

This folder contains problems based on **strings** — one of the most important data structures in DSA.  
Each subfolder focuses on a specific **technique or pattern** (like Greedy, Hash Map, Two Pointers, etc.) used to solve string-related problems efficiently.

---

## 📂 Folder Structure

| Folder | Description |
|---------|-------------|
| [`greedy`](./greedy) | Problems that use greedy techniques to process or convert strings efficiently. |
| [`sliding-window`](./sliding-window) | Problems that use sliding-window techniques to process or convert strings efficiently. |
| [`two-pointers`](./two-pointers) | Problems that use two-pointers techniques to process or convert strings efficiently. |
| *(more coming soon...)* | Additional patterns will be added here. |

---

## 🧠 Purpose
- Understand different approaches for string-based problems.  
- Practice multiple patterns to build problem-solving flexibility.  
- Prepare for **coding interviews** by recognizing which pattern applies to which problem.

---

> 💡 *Start from simple problems and gradually move to optimized approaches.*
