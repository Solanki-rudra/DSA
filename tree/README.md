# 🔗 Tree Problems

This folder contains **tree** problems — a core data structure in DSA and
commonly asked in coding interviews.

A tree is a hierarchical structure consisting of nodes with a single root and
zero or more children. Common tree types include binary trees, binary search
trees (BST), and n-ary trees. Typical operations and concepts include node
creation, insertion, deletion (for BSTs), and traversals (DFS, BFS).

---

| Folder | Description |

---

## 🧠 Key Learnings

- Tree fundamentals: nodes, root, leaves, height/depth, and parent/child relations
- Traversal strategies (preorder, inorder, postorder, level-order) and when to use each
- Recursive vs iterative implementations; using stacks and queues appropriately
- Complexity trade-offs: time is usually O(n); space depends on tree height or width

---

## 📚 Common Tree Problems

Tree problems commonly include:
- Breadth-First Search (BFS) / Level-order traversal
- Depth-First Search (DFS): preorder, inorder, postorder
- Maximum depth / minimum depth of a binary tree
- Path sum and root-to-leaf path problems
- Lowest Common Ancestor (LCA)
- Serialize and deserialize a binary tree
- Invert/flip a binary tree
- Validate Binary Search Tree (BST) and BST operations
- Diameter of a binary tree
- Balanced tree checks (height-balanced)
