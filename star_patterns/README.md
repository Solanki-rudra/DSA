# ⭐ Star Pattern Programs

This folder contains various **star and number pattern programs** written in JavaScript.  
Each pattern helps improve logic building, looping concepts, and nested loop understanding.

---

## 📂 File: `patterns.js`

### 📘 Description
This file includes multiple functions (`pattern1` to `pattern18`) that print different patterns using loops.  
Each function takes a single parameter `n` (number of rows) and logs the pattern in the console.

---

## 🧩 Pattern List

| No. | Function | Description |
|-----|-----------|-------------|
| 1 | `pattern1(n)` | Square of `*` (n × n) |
| 2 | `pattern2(n)` | Right-angled triangle of `*` |
| 3 | `pattern3(n)` | Right-angled triangle with numbers (1 to i) |
| 4 | `pattern4(n)` | Right-angled triangle with same number in each row |
| 5 | `pattern5(n)` | Inverted right-angled triangle of `*` |
| 6 | `pattern6(n)` | Inverted triangle with numbers (1 to n-i+1) |
| 7 | `pattern7(n)` | Pyramid of `*` |
| 8 | `pattern8(n)` | Inverted pyramid of `*` |
| 9 | `pattern9(n)` | Diamond shape of `*` |
| 10 | `pattern10(n)` | Mirror triangle pattern (up + down) |
| 11 | `pattern11(n)` | Binary triangle (1 and 0 alternating) |
| 12 | `pattern12(n)` | Number pattern with mirror reflection |
| 13 | `pattern13(n)` | Increasing sequence numbers in triangle form |
| 14 | `pattern14(n)` | Alphabet pattern (A, AB, ABC, ...) |

| 16 | `pattern16(n)` | Symmetric hourglass pattern of `*` |
| 17 | `pattern17(n)` | Hollow square of `*` |
| 18 | `pattern18(n)` | Number square pattern with layers |
